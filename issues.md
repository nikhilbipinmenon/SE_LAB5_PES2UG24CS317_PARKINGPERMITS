# Lab 5: Static Code Analysis — Issues Log
## Problem Statement: Campus Parking Permit Manager (`parking_system.py`)

| Issue | Type | Line(s) | Description | Fix Approach |
| :--- | :--- | :--- | :--- | :--- |
| **Insecure Pseudo-Random Number Generator** | Security (Bandit B311) | 11 | Using standard `random.randint()` for generating permit numbers is cryptographically insecure and predictable for authentication/authorization credentials. | Replaced `random` with cryptographically secure `secrets.randbelow(90000) + 10000`. |
| **Bare Except with Silent Pass** | Security & Error Handling (Bandit B110, Pylint W0702, Flake8 E722) | 22–23 | Catching bare `except:` and silencing with `pass` hides critical runtime errors and bugs (e.g., unexpected TypeErrors or KeyboardInterrupt). | Replaced with atomic `permits.pop(vehicle_plate, None)` and caught specific exceptions (`TypeError`, `ValueError`). |
| **Dangerous Mutable Default Argument** | Bug / Quality (Pylint W0102) | 9 | `def register_permit(..., zone_records=[])` retains mutated list across multiple function calls, causing state leakage between calls. | Changed default value to `None` and initialized `if zone_records is None: zone_records = []` inside the function. |
| **Unclosed File Handles & Missing Encoding** | Resource Leak / Quality (Pylint R1732, W1514) | 42, 47 | Calling `open()` without `with` context manager risks resource leaks if exceptions occur. Missing `encoding="utf-8"` causes platform-dependent character corruption. | Refactored file I/O to use `with open(file, mode, encoding="utf-8") as f:` context managers. |
| **Global State Mutation** | Code Smell (Pylint W0603) | 40 | `load_permit_database` used `global permits`, which breaks encapsulation and makes modular testing difficult. | Updated the dictionary in-place using `permits.clear()` and `permits.update(data)` without requiring the `global` statement. |
| **Non-PEP 8 Function Naming** | Style (Pylint C0103) | 51 | Function `setExpiry` used camelCase instead of PEP 8 compliant snake_case `set_expiry`. | Renamed function to `set_expiry` and added an alias `setExpiry = set_expiry` for backward compatibility. |
| **Missing Module and Function Docstrings** | Documentation / Convention (Pylint C0114, C0116) | 1, 9, 19, 25, 32, 39, 46, 51, 54 | File and functions lacked descriptive docstrings explaining their parameters, behavior, and returns. | Added comprehensive PEP 257 compliant docstrings to the module and all functions. |
| **Line Length & Spacing Violations** | Style (Flake8 E302, E305, E501) | Multiple | Multiple lines exceeded 79/100 characters and had single instead of double blank lines between top-level functions. | Re-formatted code with proper 2-blank-line separation and wrapped long statements within 79 characters. |
| **Missing Input Validation & Date Parsing Mismatch** | Functional Logic Bug | 56–60 | Program accepted empty strings `""` and `None` as valid vehicle plates, and invalid zone "Z". `is_expired` failed on dates formatted as `%d/%m/%Y`. | Added plate validation (`strip().upper()`), zone check (`zone_id in ZONES`), and multi-format date parsing (`%Y-%m-%d`, `%d/%m/%Y`). |
